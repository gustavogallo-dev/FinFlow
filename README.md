# FinFlow

> A modern SaaS platform for financial management built with React, Spring Boot, and PostgreSQL.

## 📖 About

FinFlow is a Software as a Service (SaaS) platform designed to simplify financial management for small and medium-sized businesses.

The application provides an intuitive environment for managing financial transactions, monitoring cash flow, and analyzing business performance through interactive dashboards.

---

## ✨ Features

### Version 1.0

- User authentication
- Company management
- Financial transactions
- Categories
- Interactive dashboard
- Cash flow monitoring
- User profile management
- Password recovery
